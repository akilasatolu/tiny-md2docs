# 多言語

1つのサイトに、複数の言語のページを置けます。

## 言語の決まり方

ページの言語は、ファイル名で決まります。

| ファイル名 | 言語 |
| --- | --- |
| `config.md` | サイト全体の言語(`lang`) |
| `config.ja.md` | `ja` |
| `config.zh-CN.md` | `zh-CN` |

- `.md` の直前の部分が、小文字2文字の言語コード(ISO 639-1)のときに、言語とみなします。`zh-CN` のように、`-` のあとに地域を付けられます。
- `node.js.md` のような名前は、言語とみなしません。`config.ts.md` のように、末尾がたまたま言語コードと同じ名前は、その言語になります。
- `lang` がなければ、サイト全体の言語は `en` です。

言語は、ページの `<html lang>`、画面の文言、サイドバー、検索に使われます。

## ファイルの置き方

翻訳は、元のページの隣に、ファイル名に言語を足して置きます。設定は要りません。

```text
docs/
  index.md
  index.ja.md
  guide/
    config.md
    config.ja.md
    config.ko.md
```

- ページどうしのリンクは、同じ言語のファイル名で書きます。たとえば `config.ja.md` からトップページへのリンク先は、`../index.ja.md` と書きます。`index.md` へのリンクは、サイト全体の言語のページに移ります。
- 言語ごとのトップページは `index.<言語>.md` で、URL は `/index.<言語>.html` です。
- `README.<言語>.md` は、フォルダのトップページになりません。

## 画面の文言

テーマが持っている画面の文言は、英語だけです。英語以外の言語では、`theme_options.strings` に、言語ごとに文言を書きます。`strings` のどこにも書かなかったキーは、英語で出ます。

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

キーの一覧と英語の文言は [theme_options](../reference/theme-options.ja.md) の「画面の文言」にあります。`ja` と `ko` の文言をすべて書いた例は、このドキュメントの [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml) です。

## サイドバーと検索

サイドバーと検索には、今のページと同じ言語のページだけが出ます。言語をまたいだ検索はできません。

自動の並びでは、グループ名はそのフォルダの `index.<言語>.md`(サイト全体の言語では `index.md`)の最初の見出しです。なければフォルダ名です。

`nav.yml` で並べるときは、言語ごとに `docs/_data/nav.ja.yml` のようなファイルを置きます。言語のファイルがなければ `nav.yml` を使います。`nav.yml` の項目は言語で絞られず、書いたものがそのまま出ます。翻訳したページの URL は `/guide/config.ja.html` のように書きます。

## 言語の切り替え

同じフォルダで、言語を除いた名前が同じファイルを、翻訳どうしとみなします(`config.md` と `config.ja.md`)。ヘッダーに言語のボタンが出て、押すと開く一覧から言語を切り替えられます。翻訳のないページには、言語のボタンは出ません。

言語のリンクは、サイト全体の言語が先頭に、ほかは言語名の順に並びます。

ヘッダーのサイト名のリンクは、どの言語のページからも、サイトのルート(`lang` の言語のトップページ)に行きます。

## 404 ページ

404 ページは、サイト全体の `lang` の言語で出ます。
