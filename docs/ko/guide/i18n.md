# 다국어

하나의 사이트에 여러 언어의 페이지를 둘 수 있습니다.

## 파일 배치

사이트 전체 언어(`lang`)의 페이지는 `docs/` 바로 아래에, 번역은 언어 이름의 폴더에 둡니다. 설정은 필요 없습니다.

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

- `docs/` 바로 아래에서 `ja`나 `zh-CN`처럼 소문자 두 글자의 언어 코드(ISO 639-1. 지역은 `-` 뒤)를 이름으로 한 폴더가 언어 폴더입니다. `it/`이나 `id/` 같은 이름의 보통 폴더도 언어로 봅니다.
- 사이트 전체 언어 이름의 폴더(`lang`이 `en`일 때의 `en/`)는 만들지 않습니다. 사이트의 입구 페이지가 없어지거나 같은 페이지가 두 번 나옵니다. `lang`이 없으면 사이트 전체의 언어는 `en`입니다.
- 언어 폴더를 뺀 경로가 같은 파일이 서로 번역입니다(`guide/config.md`와 `ja/guide/config.md`).
- 언어별 첫 페이지는 `ja/index.md`이고 URL은 `/ja/`입니다.
- 상대 경로로 쓴 링크는 같은 언어 폴더 안으로 이동합니다. 공통 이미지의 경로는 언어 폴더 안에서는 `../`가 하나 더 필요합니다.

언어는 페이지의 `<html lang>`, 사이드바, 검색에 쓰입니다.

## 화면의 문구

테마의 화면 문구는 영어뿐이며 바꿀 수 없습니다. 본문, `<html lang>`, 사이드바, 검색, 언어 전환은 언어별로 됩니다.

## 사이드바와 검색

사이드바와 검색에는 현재 페이지와 같은 언어의 페이지만 나옵니다. 언어를 넘나드는 검색은 할 수 없습니다.

자동 정렬에서 그룹 이름은 언어 폴더 안의 해당 폴더에 있는 `index.md`(없으면 `README.md`)의 첫 제목입니다. 없으면 폴더 이름입니다.

`nav.yml`로 정렬할 때는 언어별로 `docs/_data/nav.ko.yml` 같은 파일을 둡니다. 그 언어의 파일이 없으면 `nav.yml`을 씁니다. `nav.yml`의 항목은 언어로 걸러지지 않고 쓴 그대로 나옵니다. 번역한 페이지의 URL은 `/ko/guide/config.html`처럼 씁니다.

## 언어 전환

번역이 있는 페이지에는 헤더에 언어 버튼이 나옵니다. 누르면 열리는 목록에서 언어를 전환할 수 있습니다. 번역이 없는 페이지에는 언어 버튼이 나오지 않습니다.

언어 링크는 사이트 전체의 언어가 맨 앞에, 나머지는 언어 이름 순으로 놓입니다.

헤더의 사이트 이름 링크는 어느 언어의 페이지에서든 사이트의 루트(`lang` 언어의 최상위 페이지)로 갑니다.

## 404 페이지

404 페이지는 사이트 전체 `lang`의 언어로 나옵니다.
