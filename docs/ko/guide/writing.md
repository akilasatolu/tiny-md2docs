# 페이지 작성법

페이지는 보통의 Markdown으로 씁니다. 여기서는 페이지와 링크를 쓰는 방법, 그리고 테마가 제공하는 표시를 소개합니다.

본문에서 사용할 수 있는 작성법은 [표시 예시](elements.md)에서 예시로 볼 수 있습니다. 버튼이나 배지 등의 클래스는 [UI 구성 요소](ui-parts.md)에 있습니다.

## 페이지와 링크

- 페이지 맨 앞의 front matter(`---`로 둘러싼 설정)는 없어도 됩니다. 페이지의 이름에는 본문의 첫 제목이 쓰입니다. 쓸 수 있는 항목은 [front matter](../reference/front-matter.md)에 있습니다.
- 페이지끼리의 링크는 링크 대상 `.md` 파일로의 상대 경로로 씁니다. 공개할 때 `.html` 페이지로의 링크로 바뀝니다. 예를 들어 이 페이지(`docs/guide/writing.md`)에서 [개요](../index.md)로 가는 링크는 `../index.md`라고 씁니다.
- `/`로 시작하는 경로(`/guide/config.md` 등)는 쓰지 않습니다. `docs/` 바로 아래의 페이지 이외에서는 링크가 변환되지 않아 끊어집니다.
- `.html` 링크를 직접 쓰는 것도 피합니다. `/`로 시작하는 `.html` 링크는 프로젝트 페이지(`https://user.github.io/repo/`)에서 끊어집니다.

## 목차

페이지에 h2와 h3 제목이 둘 이상 있으면 목차가 나옵니다. 넓은 화면에서는 본문 오른쪽에, 좁은 화면에서는 본문 위에 접어서 나옵니다. 읽고 있는 제목은 목차 안에서 강조됩니다.

목차를 끌 때는 페이지의 front matter에 `toc: false`를 씁니다. 사이트 전체에서 끄려면 `theme_options.toc: false`로 합니다.

일부 제목만 목차에서 빼려면 제목 다음 줄에 `{: .no_toc }`를 씁니다. 뺀 제목도 검색에서는 찾을 수 있습니다.

```markdown
## 참고
{: .no_toc }
```

## 이동 경로(브레드크럼)

페이지 위에 사이드바에서의 그룹 위치('사용법 / 설정' 등)가 나옵니다. 이동할 페이지가 있는 그룹은 링크가 됩니다(`nav.yml`에서는 그룹의 `url`, 자동 정렬에서는 폴더의 `index.md`). 최상위 페이지와 그룹에 들어 있지 않은 페이지에는 나오지 않습니다. `theme_options.breadcrumb: false`로 끌 수 있습니다.

## 주의 문구 상자

인용(`>`)의 마지막 줄 다음 줄에 `{: .note }` 또는 `{: .warning }`을 쓰면 색이 있는 상자가 됩니다. 제목을 붙일 때는 `{: .note data-title="메모" }`처럼 씁니다. 본문 맨 앞에 라벨을 직접 쓸 수도 있습니다.

```markdown
> **메모** 설정을 바꾼 뒤에는 몇 분 기다렸다가 확인합니다.
{: .note }

> **주의** 이 작업은 되돌릴 수 없습니다.
{: .warning }
```

> **메모** 설정을 바꾼 뒤에는 몇 분 기다렸다가 확인합니다.
{: .note }

> **주의** 이 작업은 되돌릴 수 없습니다.
{: .warning }

제목을 붙인 예입니다.

```markdown
> 계속하기 전에 파일을 저장합니다.
{: .note data-title="메모" }
```

> 계속하기 전에 파일을 저장합니다.
{: .note data-title="메모" }

여러 줄이나 여러 단락도 쓸 수 있습니다. 각 줄의 맨 앞에 `>`를 붙이고, 단락을 나누는 곳에는 `>`만 있는 줄을 넣습니다. `{: .note }`는 마지막 줄 다음 줄에 씁니다. 이어서 쓴 줄은 표시할 때 한 줄로 이어집니다.

```markdown
> **메모** 첫 번째 단락입니다.
> 이어서 쓴 줄은 같은 단락이 됩니다.
>
> 두 번째 단락입니다.
>
> - 목록도 쓸 수 있습니다
{: .note }
```

> **메모** 첫 번째 단락입니다.
> 이어서 쓴 줄은 같은 단락이 됩니다.
>
> 두 번째 단락입니다.
>
> - 목록도 쓸 수 있습니다
{: .note }

## 코드 복사

코드 블록에 마우스를 올리면 오른쪽 위에 복사 버튼이 나옵니다. 터치 화면에서는 항상 나와 있습니다. `theme_options.code_copy: false`로 끌 수 있습니다.

```bash
bundle exec jekyll serve
```

## 제목 링크

h2부터 h6까지의 제목에 마우스를 올리면 그 제목으로 가는 `#` 링크가 나옵니다. 터치 화면에서는 항상 나와 있습니다. 이 링크에는 JavaScript가 필요합니다. `theme_options.heading_link: false`로 끌 수 있습니다.

## 맨 위로 가기

본문 아래에 페이지 맨 위로 가는 링크가 나옵니다. `theme_options.top_link: false`로 끌 수 있습니다.

## 인쇄

페이지를 인쇄하면 헤더, 사이드바, 목차, 이전·다음 링크, 복사 버튼 등을 빼고 밝은 색으로 나옵니다.
