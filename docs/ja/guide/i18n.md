# 多言語

1つのサイトに、複数の言語のページを置けます。

## 言語の決まり方

ページの言語は、次の2つで決めます。

1. 言語の名前のフォルダと `defaults`: そのフォルダの中のページの言語
2. サイト全体の `lang`: 1 に当てはまらないページの言語

1 は 2 より優先します。どちらもなければ `en` です。

言語は、ページの `<html lang>`、画面の文言、サイドバー、検索に使われます。

## 言語ごとにフォルダを分ける

サイト全体の言語のページはこれまでどおりに置き、ほかの言語のページは、言語の名前のフォルダに置きます。

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

`docs/_config.yml` の `defaults` で、フォルダの中のページに言語を付けます。

```yaml
lang: en
defaults:
  - scope:
      path: ja
    values:
      lang: ja
  - scope:
      path: ko
    values:
      lang: ko
```

- `defaults` には、言語ごとに1つずつ項目を書きます。
- `scope` の `path` には、言語のフォルダのパスを `docs/` から書きます(`docs/ja` ではなく `ja`)。
- `values` の `lang` には、その言語の名前を書きます。
- フォルダの名前と `lang` の値は、同じにします。違うと、サイドバーでそのフォルダが1段のグループとして数えられます。
- 言語の名前は、文字がそのまま同じかどうかで比べます。`ja` と `ja-JP` は別の言語になるので、サイトの中で書き方をそろえます。

## 画面の文言

テーマが持っている画面の文言は、英語だけです。英語以外の言語では、`theme_options.strings` に、言語ごとに文言を書きます。`strings` のどこにも書かなかったキーは、英語で出ます。

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

キーの一覧と英語の文言は [theme_options](../reference/theme-options.md) の「画面の文言」にあります。`ja` と `ko` の文言をすべて書いた例は、このドキュメントの [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml) です。

## サイドバーと検索

サイドバーと検索には、今のページと同じ言語のページだけが出ます。言語をまたいだ検索はできません。

自動の並びでは、言語のフォルダ(`ja/`)は無いものとして並べます。`docs/ja/index.md` がその言語のトップページになります。グループ名を言語ごとに変えるときは、言語のフォルダの中のフォルダに `index.md` を置き、`title` を書きます(例: `docs/ja/guide/index.md` に `title: 使い方`)。

`nav.yml` で並べるときは、言語ごとに `docs/_data/nav.ja.yml` のようなファイルを置きます。言語のファイルがなければ `nav.yml` を使います。`nav.yml` の項目は言語で絞られず、書いたものがそのまま出ます。

## 言語の切り替え

翻訳どうしのページの front matter に、同じ `ref` を書きます。ヘッダーに、言語を切り替えるリンクが出ます。

```markdown
---
ref: config
---

# 設定
```

ヘッダーのサイト名のリンクは、どの言語のページからも、サイトのルート(`lang` の言語のトップページ)に行きます。

## 404 ページ

404 ページは、サイト全体の `lang` の言語で出ます。
