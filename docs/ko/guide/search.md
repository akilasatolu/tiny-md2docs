# 검색

헤더의 검색창으로 사이트 안의 페이지를 검색할 수 있습니다. 외부 서비스는 쓰지 않고, 빌드할 때 만든 색인을 브라우저에서 검색합니다.

## 사용법

- `/` 키로 검색창으로 이동합니다.
- 입력하면 제목, 제목 줄(소제목), 본문에서 일치하는 페이지가 최대 10개 나옵니다.
- 결과가 나오면 첫 페이지가 선택된 상태(색이 붙음)가 됩니다. ↑↓ 키로 선택을 바꾸고, Enter로 선택한 페이지를 엽니다. Esc로 결과를 닫습니다.
- Tab 키로 검색창 오른쪽 끝의 ×, 결과의 각 페이지 순으로 이동할 수 있습니다. 결과 페이지에서 Enter를 누르면 열리고, Esc를 누르면 검색창으로 돌아갑니다.
- 입력 중에는 검색창 오른쪽 끝의 ×로 입력을 지울 수 있습니다.

## 일본어·중국어·한국어 검색

일본어, 중국어, 한국어는 두 글자씩 겹쳐 자른 쌍으로 대조합니다(예: '設定変更'은 '設定', '定変', '変更'). 그래서 단어의 구분이 없어도 문장 중간의 단어가 검색됩니다.

검색 전에 다음과 같이 글자를 맞춥니다.

- 전각 영숫자와 반각 가타카나는 보통 글자로 맞춥니다. 'ＡＢＣ'는 'abc'로, 'ｶﾞｲﾄﾞ'는 'ガイド'로 검색됩니다.
- 가타카나와 히라가나는 구별하지 않습니다. 'がいど'로도 'ガイド'가 검색됩니다.
- 영문 대소문자와 악센트 기호는 구별하지 않습니다. 'café'는 'cafe'로 검색됩니다.
- 탁점과 반탁점은 구별합니다. 'が'로 'か'는 검색되지 않습니다.

여러 단어를 공백으로 구분하면 모든 단어를 포함한 페이지만 나옵니다.

## 검색에서 제외하기

페이지의 front matter에 `search_exclude: true`를 쓰면 그 페이지는 검색에 나오지 않습니다. 사이트 전체의 검색을 끄려면 `theme_options.search: false`로 합니다.

색인에 넣는 본문은 한 페이지당 5000자까지입니다. `theme_options.search_content_limit`로 바꿀 수 있습니다. 페이지가 많아 색인이 무거울 때는 작게 합니다.
