# 검색

헤더의 검색창으로 사이트 안의 페이지를 검색할 수 있습니다. 외부 서비스는 쓰지 않고, 빌드할 때 만든 색인을 브라우저에서 검색합니다.

## 사용법

- `/` 키로 검색창으로 이동합니다.
- 입력하면 제목, 제목 줄(소제목), 본문에서 일치하는 페이지가 최대 10개 나옵니다.
- 결과가 나오면 첫 페이지가 선택된 상태(색이 붙음)가 됩니다. ↑↓ 키로 선택을 바꾸고, Enter로 선택한 페이지를 엽니다. Esc로 결과를 닫습니다.
- Tab 키로 검색창 오른쪽 끝의 ×, 결과의 각 페이지 순으로 이동할 수 있습니다. 결과 페이지에서 Enter를 누르면 열리고, Esc를 누르면 검색창으로 돌아갑니다.
- 입력 중에는 검색창 오른쪽 끝의 ×로 입력을 지울 수 있습니다.

## 지원하는 언어

검색은 글자의 종류에 따라 대조하는 방법을 바꿉니다.

| 글자의 종류 | 예 | 대조하는 방법 |
| --- | --- | --- |
| 한자, 히라가나, 가타카나, 한글 | 일본어, 중국어, 한국어 | 두 글자씩 겹쳐 자른 쌍 |
| 라틴 문자, 키릴 문자처럼 단어를 공백으로 구분해 쓰는 언어 | 영어, 프랑스어, 독일어, 베트남어, 러시아어, 아랍어와 히브리어(모음 기호를 붙이지 않고 쓴 경우) | 단어 |

- 중국어의 간체자와 번체자는 다른 글자로 취급합니다. '設置'로 '设置'는 검색되지 않습니다.
- 러시아어의 'й'와 'и', 'ё'와 'е'는 같은 글자로 취급합니다.
- 단어 사이에 공백을 두지 않는 언어(태국어 등)는 동작을 보장하지 않습니다. 공백이나 기호 사이가 통째로 한 단어가 되므로, 단어의 중간부터 검색하면 찾지 못합니다.
- 모음 기호 같은 결합 기호를 쓰는 언어(태국어, 힌디어, 모음 기호를 붙인 아랍어나 히브리어 등)는 동작을 보장하지 않습니다. 기호에서 단어가 끊기므로, 페이지를 찾지 못하거나 관계없는 페이지가 섞일 수 있습니다.
- 언어별 사전은 갖고 있지 않습니다. 단어의 구분은 글자의 종류만으로 정합니다.

## 일본어·중국어·한국어 검색

일본어, 중국어, 한국어는 두 글자씩 겹쳐 자른 쌍으로 대조합니다(예: '設定変更'은 '設定', '定変', '変更'). 그래서 단어의 구분이 없어도 문장 중간의 단어가 검색됩니다.

다만 공백 없이 이어서 입력한 한자·가나·한글은 제목, 소제목, 본문 중 어딘가에 **그대로 이어진 형태로** 들어 있는 페이지만 나옵니다. '東京都'로는 '東京と京都'라고만 쓴 페이지가 나오지 않습니다.

검색 전에 다음과 같이 글자를 맞춥니다.

- 전각 영숫자와 반각 가타카나는 보통 글자로 맞춥니다. 'ＡＢＣ'는 'abc'로, 'ｶﾞｲﾄﾞ'는 'ガイド'로 검색됩니다.
- 가타카나와 히라가나는 구별하지 않습니다. 'がいど'로도 'ガイド'가 검색됩니다.
- 네 글자 이상의 가타카나 단어 끝의 장음 'ー'는 무시하므로 'サーバー'와 'サーバ'는 같습니다. 히라가나로 입력한 네 글자 이상의 단어 끝의 'ー'도 같습니다. 'コピー', 'キー' 같은 짧은 단어는 그대로입니다.
- 영문 대소문자와 악센트 기호는 구별하지 않습니다. 'café'는 'cafe'로 검색됩니다.
- 탁점과 반탁점은 구별합니다. 'が'로 'か'는 검색되지 않습니다.

여러 단어를 공백으로 구분하면 모든 단어를 포함한 페이지만 나옵니다.

한 건도 찾지 못하면, 한자·가타카나·영숫자 사이에 낀 일본어 조사(の, を, に, は, が, で, と, へ, も, や, から, まで, より, など)를 공백으로 바꿔 다시 검색합니다. '設定の方法'로 '設定方法'라고 쓴 페이지를 찾습니다.

## 검색 사양

- 검색 대상: 현재 페이지와 같은 언어(`<html lang>`)의 페이지만입니다. 언어를 나누는 방법은 [다국어](i18n.md)를 보세요.
- 단어를 나누는 방법: 한자, 히라가나, 가타카나, 한글은 위의 '일본어·중국어·한국어 검색'처럼 두 글자씩 겹쳐 자른 쌍으로 나눕니다. 그 밖의 글자는 글자와 숫자가 이어진 부분을 한 단어로 봅니다. `_`, `-`, `.` 같은 기호로 구분하므로 `theme_options`는 `theme`과 `options`의 두 단어입니다. 쌍은 순위 점수에 씁니다. 일치하려면 위에서 설명한 대로 이어진 형태로 들어 있어야 합니다.
- 한 글자 단어: 쌍이나 단어로 대조하지 않고, 그 한 글자가 제목, 소제목, 본문 어딘가에 들어 있는 페이지를 찾습니다.
- 마지막 단어의 앞부분 일치: 단어 단위로 대조하는 언어에서는 입력한 마지막 단어를 앞부분 일치로 찾습니다. 'caf'로 'café'가 검색됩니다.
- 한 글자 차이: 단어 단위로 대조하는 언어에서 네 글자 이상의 단어가 일치하지 않으면, 한 글자 차이(한 글자의 추가, 삭제, 교체)인 단어도 찾습니다. 'serch'로 'search'가 검색됩니다. 글자 순서가 바뀐 경우('seacrh')는 찾지 못합니다.

## 순위

입력한 단어마다 일치한 곳의 점수를 더하고, 합계가 큰 순서로 나열합니다.

| 위치 | 점수 |
| --- | --- |
| 제목 | 10 |
| 소제목 | 4 |
| 본문 | 1(여기에 같은 단어가 나올 때마다 0.2를 더함. 5번까지) |

- 제목에 입력한 어구 전체가 들어 있으면 5를 더합니다.
- 한 글자 차이로 일치한 단어는 점수가 절반이 됩니다.
- 브라우저가 `Intl.Segmenter`를 지원하면, 단어로 나눌 수 있는 단어가 일치할 때 그 위치 점수의 절반을 더합니다. 일치하는 페이지는 바뀌지 않고 순위에만 영향을 줍니다.
- 점수가 같으면 제목이 짧은 페이지가 먼저, 그다음은 URL 순입니다.

## 검색에서 제외하기

페이지의 front matter에 `search_exclude: true`를 쓰면 그 페이지는 검색에 나오지 않습니다. 사이트 전체의 검색을 끄려면 `theme_options.search: false`로 합니다.

색인에 넣는 본문은 한 페이지당 5000자까지입니다. `theme_options.search_content_limit`로 바꿀 수 있습니다. 페이지가 많아 색인이 무거울 때는 작게 합니다.
