# ページの書き方

ページは、ふつうの Markdown で書きます。ここでは、ページとリンクの書き方と、テーマが用意している表示を紹介します。

本文で使える書き方は、[表示の一覧](elements.md)に見本があります。

## ページとリンク

- ページの先頭の front matter(`---` で囲んだ設定)は、なくてもかまいません。ページの名前には、本文の最初の見出しが使われます。書ける項目は [front matter](../reference/front-matter.md) にあります。
- ページどうしのリンクは、リンク先の `.md` ファイルへの相対パスで書きます。公開するときに、`.html` のページへのリンクに変わります。たとえばこのページ(`docs/guide/writing.md`)から[概要](../index.md)へのリンクは、`../index.md` と書きます。
- `/` で始まるパス(`/guide/config.md` など)は使いません。`docs/` の直下のページ以外では、リンクが変換されずに切れます。
- `.html` へのリンクを直接書くのも避けます。`/` で始まる `.html` のリンクは、プロジェクトのページ(`https://user.github.io/repo/`)で切れます。

## 目次

ページに h2 と h3 の見出しが2つ以上あると、目次が出ます。広い画面では本文の右に、狭い画面では本文の上に折りたたんで出ます。読んでいる見出しは、目次の中で強調されます。

目次を消すときは、ページの front matter に `toc: false` を書きます。サイト全体で消すときは `theme_options.toc: false` にします。

一部の見出しだけを目次から外すときは、見出しの次の行に `{: .no_toc }` を書きます。外した見出しも、検索では見つかります。

```markdown
## 補足
{: .no_toc }
```

## パンくず

ページの上に、サイドバーでのグループの位置(「使い方 / 設定」など)が出ます。移動先のページがあるグループは、リンクになります(`nav.yml` ではグループの `url`、自動の並びではフォルダの `index.md`)。トップページと、グループに入っていないページには出ません。`theme_options.breadcrumb: false` で消せます。

## 注意書きの囲み

引用(`>`)の最後の行の次に `{: .note }` か `{: .warning }` を書くと、色の付いた囲みになります。タイトルを付けるときは `{: .note data-title="メモ" }` のように書きます。本文の先頭に自分でラベルを書くこともできます。

```markdown
> **メモ** 設定を変えたら、数分待ってから確かめます。
{: .note }

> **注意** この操作は元に戻せません。
{: .warning }
```

> **メモ** 設定を変えたら、数分待ってから確かめます。
{: .note }

> **注意** この操作は元に戻せません。
{: .warning }

タイトルを付けた例です。

```markdown
> 続ける前にファイルを保存します。
{: .note data-title="メモ" }
```

> 続ける前にファイルを保存します。
{: .note data-title="メモ" }

複数の行や段落も書けます。各行の先頭に `>` を付け、段落を分けるところには `>` だけの行を入れます。`{: .note }` は、最後の行の次に書きます。続けて書いた行は、表示では1行につながります。

```markdown
> **メモ** 1つ目の段落です。
> 続けて書いた行は、同じ段落になります。
>
> 2つ目の段落です。
>
> - リストも書けます
{: .note }
```

> **メモ** 1つ目の段落です。
> 続けて書いた行は、同じ段落になります。
>
> 2つ目の段落です。
>
> - リストも書けます
{: .note }

## コードのコピー

コードのブロックにマウスを重ねると、右上にコピーのボタンが出ます。タッチ操作の画面では、いつも出ています。`theme_options.code_copy: false` で消せます。

```bash
bundle exec jekyll serve
```

## 見出しのリンク

h2 から h6 の見出しにマウスを重ねると、その見出しへの `#` のリンクが出ます。タッチ操作の画面では、いつも出ています。このリンクには JavaScript が必要です。`theme_options.heading_link: false` で消せます。

## ページ先頭へ戻る

本文の下に、ページの先頭へ戻るリンクが出ます。`theme_options.top_link: false` で消せます。

## 印刷

ページを印刷すると、ヘッダー、サイドバー、目次、前後リンク、コピーのボタンなどを除き、明るい色で出ます。
