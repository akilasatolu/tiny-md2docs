# 多言語

1つのサイトに、複数の言語のページを置けます。

## ファイルの置き方

サイト全体の言語(`lang`)のページは `docs/` の直下に、翻訳は言語の名前のフォルダに置きます。設定は要りません。

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

- `docs/` の直下の、`ja` や `zh-CN` のように小文字2文字の言語コード(ISO 639-1。地域は `-` のあと)の名前のフォルダが、言語のフォルダです。`it/` や `id/` のような名前の普通のフォルダも、言語とみなされます。
- サイト全体の言語の名前のフォルダ(`lang` が `en` のときの `en/`)は作りません。サイトの入口のページがなくなるか、同じページが2つ出ます。`lang` がなければ、サイト全体の言語は `en` です。
- 言語のフォルダを除いたパスが同じファイルが、翻訳どうしです(`guide/config.md` と `ja/guide/config.md`)。
- 言語ごとのトップページは `ja/index.md` で、URL は `/ja/` です。
- 相対パスで書いたリンクは、同じ言語のフォルダの中に移ります。共通の画像へのパスは、言語のフォルダの中では `../` が1つ多くなります。

言語は、ページの `<html lang>`、サイドバー、検索に使われます。

## 画面の文言

テーマの画面の文言は英語だけで、変えられません。本文、`<html lang>`、サイドバー、検索、言語の切り替えは、言語ごとになります。

## サイドバーと検索

サイドバーと検索には、今のページと同じ言語のページだけが出ます。言語をまたいだ検索はできません。

自動の並びでは、グループ名は、言語のフォルダの中の、そのフォルダの `index.md`(なければ `README.md`)の最初の見出しです。なければフォルダ名です。

`nav.yml` で並べるときは、言語ごとに `docs/_data/nav.ja.yml` のようなファイルを置きます。言語のファイルがなければ `nav.yml` を使います。`nav.yml` の項目は言語で絞られず、書いたものがそのまま出ます。翻訳したページの URL は `/ja/guide/config.html` のように書きます。

## 言語の切り替え

翻訳のあるページには、ヘッダーに言語のボタンが出ます。押すと開く一覧から言語を切り替えられます。翻訳のないページには、言語のボタンは出ません。

言語のリンクは、サイト全体の言語が先頭に、ほかは言語名の順に並びます。

ヘッダーのサイト名のリンクは、どの言語のページからも、サイトのルート(`lang` の言語のトップページ)に行きます。

## 404 ページ

404 ページは、サイト全体の `lang` の言語で出ます。
