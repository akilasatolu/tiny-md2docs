# 다국어

하나의 사이트에 여러 언어의 페이지를 둘 수 있습니다.

## 언어가 정해지는 방법

페이지의 언어는 다음 두 가지로 정합니다.

1. 언어 이름의 폴더와 `defaults`: 그 폴더 안 페이지의 언어
2. 사이트 전체의 `lang`: 1에 해당하지 않는 페이지의 언어

1이 2보다 우선합니다. 둘 다 없으면 `en`입니다.

언어는 페이지의 `<html lang>`, 화면의 문구, 사이드바, 검색에 쓰입니다.

## 언어별로 폴더 나누기

사이트 전체 언어의 페이지는 지금까지처럼 두고, 다른 언어의 페이지는 언어 이름의 폴더에 둡니다.

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

`docs/_config.yml`의 `defaults`로 폴더 안 페이지에 언어를 붙입니다.

```yaml
lang: en
defaults:
  - scope:
      path: ja
    values:
      lang: ja
  - scope:
      path: ko
    values:
      lang: ko
```

- `defaults`에는 언어마다 항목을 하나씩 씁니다.
- `scope`의 `path`에는 언어 폴더의 경로를 `docs/`부터 씁니다(`docs/ja`가 아니라 `ja`).
- `values`의 `lang`에는 그 언어의 이름을 씁니다.
- 폴더 이름과 `lang` 값은 같게 합니다. 다르면 사이드바에서 그 폴더가 한 단계짜리 그룹으로 세어집니다.
- 언어 이름은 글자가 그대로 같은지로 비교합니다. `ja`와 `ja-JP`는 다른 언어이므로 사이트 안에서 표기를 통일하세요.

## 화면의 문구

테마가 가진 화면의 문구는 영어뿐입니다. 영어 이외의 언어에서는 `theme_options.strings`에 언어별로 문구를 씁니다. `strings` 어디에도 쓰지 않은 키는 영어로 나옵니다.

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

키 목록과 영어 문구는 [theme_options](../reference/theme-options.md)의 '화면의 문구'에 있습니다. `ja`와 `ko`의 문구를 모두 쓴 예는 이 문서의 [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml)입니다.

## 사이드바와 검색

사이드바와 검색에는 현재 페이지와 같은 언어의 페이지만 나옵니다. 언어를 넘나드는 검색은 할 수 없습니다.

자동 정렬에서는 언어 폴더(`ja/`)가 없는 것으로 보고 정렬합니다. `docs/ja/index.md`가 그 언어의 최상위 페이지가 됩니다. 그룹 이름을 언어별로 바꿀 때는 언어 폴더 안의 폴더에 `index.md`를 두고 `title`을 씁니다(예: `docs/ja/guide/index.md`에 `title: 使い方`). 이 `index.md`는 사이드바 항목과 이전·다음 링크에도 나옵니다. 그룹 이름만 바꾸고 싶을 때는 `nav_exclude: true`도 씁니다.

`nav.yml`로 정렬할 때는 언어별로 `docs/_data/nav.ja.yml` 같은 파일을 둡니다. 그 언어의 파일이 없으면 `nav.yml`을 씁니다. `nav.yml`의 항목은 언어로 걸러지지 않고 쓴 그대로 나옵니다.

## 언어 전환

번역 관계인 페이지의 front matter에 같은 `ref`를 씁니다. 헤더에 언어 버튼이 나오고, 누르면 열리는 목록에서 언어를 전환할 수 있습니다.

```markdown
---
ref: config
---

# 설정
```

언어 링크는 사이트 전체의 언어가 맨 앞에, 나머지는 언어 이름 순으로 놓입니다.

헤더의 사이트 이름 링크는 어느 언어의 페이지에서든 사이트의 루트(`lang` 언어의 최상위 페이지)로 갑니다.

## 404 페이지

404 페이지는 사이트 전체 `lang`의 언어로 나옵니다.
