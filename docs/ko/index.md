# 개요

tm2d(tiny-md2docs)는 GitHub Pages에서 쓰는 작은 Jekyll 테마입니다. Markdown을 `docs/`에 두기만 하면 문서 사이트로 공개할 수 있습니다.

## 특징

- 도입은 `docs/_config.yml`에 한 줄(`remote_theme`)을 쓰는 것이 전부입니다
- GitHub Pages의 표준 빌드만으로 동작합니다. 워크플로, npm, 플러그인 추가가 필요 없습니다
- 그 밖에 준비할 것이 없습니다. 사이드바, 검색, 목차, 404 페이지는 테마가 만듭니다
- 색은 CSS 변수를 덮어써서 바꿀 수 있습니다

## 이런 분에게 적합합니다

- 사내 문서를 빠르게 공개하고 싶은 팀
- 문서 공개에 시간을 들이고 싶지 않은 개인, 오픈 소스·라이브러리 개발자
