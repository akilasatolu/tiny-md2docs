# Multilingual

You can put pages in several languages on one site.

## How the language is decided

By default, the language of a page is decided by its file name. You can also [split languages by folder](#split-languages-by-folder).

| File name | Language |
| --- | --- |
| `config.md` | The language of the whole site (`lang`) |
| `config.ja.md` | `ja` |
| `config.zh-CN.md` | `zh-CN` |

- The part just before `.md` is treated as a language when it is a two-letter language code (ISO 639-1) in lowercase. A region can follow with `-`, as in `zh-CN`.
- Names such as `node.js.md` are not treated as a language. A name whose last part happens to be a language code, such as `config.ts.md`, is treated as that language.
- If `lang` is not set, the language of the whole site is `en`.

The language is used for the page's `<html lang>`, the on-screen text, the sidebar, and search.

## Place the files

Put the translation next to the original page, with the language added to the file name. No setting is needed.

```text
docs/
  index.md
  index.ja.md
  guide/
    config.md
    config.ja.md
    config.ko.md
```

- Write links between pages with the file name of the same language. For example, in `config.ja.md`, the link target for the top page is `../index.ja.md`. A link to `index.md` goes to the page in the language of the whole site.
- The top page of a language is `index.<language>.md`, and its URL is `/index.<language>.html`.
- A `README.<language>.md` does not become the top page of a folder.

## Split languages by folder

With `theme_options.lang_layout: folder`, the language is decided by the name of the top folder instead of the file name.

```yaml
theme_options:
  lang_layout: folder
```

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

- Put the pages in the language of the whole site (`lang`) directly under `docs/`, not in a folder. Do not make a folder with the name of that language (such as `en/` when `lang` is `en`): the site's entrance would have no page, or the same page would appear twice.
- A folder named with a two-letter lowercase language code, such as `ja` or `zh-CN` (a region follows `-`), is a language folder. An ordinary folder with such a name, such as `it/` or `id/`, is also treated as a language.
- Files whose paths are the same apart from the language folder are translations of each other (`guide/config.md` and `ja/guide/config.md`).
- The top page of a language is `ja/index.md`, and its URL is `/ja/`. In `nav.ja.yml`, write URLs such as `/ja/guide/config.html`.
- A group name in the sidebar is the first heading of the `index.md` in that folder inside the language folder.
- Links written as relative paths stay inside the same language folder.
- In this layout, `.ja` in a file name does not set the language.

## On-screen text

The theme has its built-in on-screen text in English only. For languages other than English, write the text for each language under `theme_options.strings`. Keys you do not write anywhere in `strings` appear in English.

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

The list of keys and the English text are under "On-screen text" in [theme_options](../reference/theme-options.md). For an example that writes all the text for `ja` and `ko`, see this documentation's [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml).

## Sidebar and search

The sidebar and search show only pages in the same language as the current page. You cannot search across languages.

In the automatic order, the group name is the first heading of the `index.<language>.md` in that folder (`index.md` for the language of the whole site). If there is none, it is the folder name.

To set the order with `nav.yml`, put a file such as `docs/_data/nav.ja.yml` for each language. If there is no file for the language, `nav.yml` is used. The items in `nav.yml` are not filtered by language; they appear as written. Write the URL of a translated page as `/guide/config.ja.html`.

## Switch languages

Files in the same folder whose names are the same apart from the language are treated as translations of each other (`config.md` and `config.ja.md`). A language button appears in the header. Press it and choose a language from the list that opens. A page without a translation has no language button.

The language links are ordered with the site-wide language first, then the other languages by name.

The site name link in the header goes to the site root (the top page of the language in `lang`) from a page in any language.

## 404 page

The 404 page appears in the language of the site-wide `lang`.
