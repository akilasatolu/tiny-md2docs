# 多言語

1つのサイトに、複数の言語のページを置けます。

## 言語ごとにフォルダを分ける

既定の言語のページはこれまでどおりに置き、ほかの言語のページは `docs/en/` のように言語の名前のフォルダに置きます。

```text
docs/
  index.md
  guide/config.md
  en/
    index.md
    guide/config.md
```

`docs/_config.yml` の `defaults` で、フォルダの中のページに言語を付けます。

```yaml
lang: ja
defaults:
  - scope:
      path: en
    values:
      lang: en
```

言語は、ページの `<html lang>` と、画面の文言に使われます。テーマは日本語と英語の文言を持っています。ほかの言語は `theme_options.strings` に言語ごとに書きます。

```yaml
theme_options:
  strings:
    fr:
      search_placeholder: Rechercher
      next: Suivant
```

## サイドバーと検索

サイドバーと検索には、今のページと同じ言語のページだけが出ます。言語をまたいだ検索はできません。

自動の並びでは、言語のフォルダ(`en/`)は無いものとして並べます。`docs/en/index.md` が英語のトップページになります。

`nav.yml` で並べるときは、言語ごとに `docs/_data/nav.en.yml` のようなファイルを置きます。言語のファイルがなければ `nav.yml` を使います。

## 言語の切り替え

翻訳どうしのページの front matter に、同じ `ref` を書きます。ヘッダーに、言語を切り替えるリンクが出ます。

```markdown
---
ref: config
---

# 設定
```
