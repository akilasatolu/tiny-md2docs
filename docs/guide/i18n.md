# Multilingual

You can put pages in several languages on one site.

## How the language is decided

The language of a page is decided by these two things.

1. A folder named after the language, plus `defaults`: the language of the pages in that folder
2. The site-wide `lang`: the language of pages that 1 does not apply to

1 takes priority over 2. If neither is set, it is `en`.

The language is used for the page's `<html lang>`, the on-screen text, the sidebar, and search.

## Split folders by language

Put pages in the site-wide language where you always have, and put pages in other languages in a folder named after the language.

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

In `defaults` in `docs/_config.yml`, set the language of the pages in each folder.

```yaml
lang: en
defaults:
  - scope:
      path: ja
    values:
      lang: ja
  - scope:
      path: ko
    values:
      lang: ko
```

- Write one entry in `defaults` for each language.
- In `scope`'s `path`, write the path of the language folder from `docs/` (`ja`, not `docs/ja`).
- In `values`'s `lang`, write the name of the language.
- Make the folder name and the `lang` value the same. If they differ, the sidebar counts that folder as a one-level group.
- Language names are compared character for character. `ja` and `ja-JP` are different languages, so use one spelling throughout the site.

## On-screen text

The theme has its built-in on-screen text in English only. For languages other than English, write the text for each language under `theme_options.strings`. Keys you do not write anywhere in `strings` appear in English.

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

The list of keys and the English text are under "On-screen text" in [theme_options](../reference/theme-options.md). For an example that writes all the text for `ja` and `ko`, see this documentation's [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml).

## Sidebar and search

The sidebar and search show only pages in the same language as the current page. You cannot search across languages.

In the automatic order, the language folder (`ja/`) is treated as if it were not there. `docs/ja/index.md` becomes the top page of that language. To change group names per language, put an `index.md` in a folder inside the language folder and write a `title` (for example, `title: 使い方` in `docs/ja/guide/index.md`).

To set the order with `nav.yml`, put a file such as `docs/_data/nav.ja.yml` for each language. If there is no file for the language, `nav.yml` is used. The items in `nav.yml` are not filtered by language; they appear as written.

## Switch languages

Write the same `ref` in the front matter of pages that are translations of each other. A link to switch languages appears in the header.

```markdown
---
ref: config
---

# Configuration
```

The language links are ordered with the site-wide language first, then the other languages by name.

The site name link in the header goes to the site root (the top page of the language in `lang`) from a page in any language.

## 404 page

The 404 page appears in the language of the site-wide `lang`.
