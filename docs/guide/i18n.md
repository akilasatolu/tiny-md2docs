# Multilingual

You can put pages in several languages on one site.

## Place the files

Put the pages in the language of the whole site (`lang`) directly under `docs/`, and the translations in a folder named after their language. No setting is needed.

```text
docs/
  index.md
  guide/config.md
  ja/
    index.md
    guide/config.md
  ko/
    index.md
    guide/config.md
```

- A folder directly under `docs/` named with a two-letter lowercase language code (ISO 639-1), such as `ja` or `zh-CN` (a region follows `-`), is a language folder. An ordinary folder with such a name, such as `it/` or `id/`, is also treated as a language.
- Do not make a folder for the language of the whole site (such as `en/` when `lang` is `en`): the site's entrance would have no page, or the same page would appear twice. If `lang` is not set, the language of the whole site is `en`.
- Files whose paths are the same apart from the language folder are translations of each other (`guide/config.md` and `ja/guide/config.md`).
- The top page of a language is `ja/index.md`, and its URL is `/ja/`.
- Links written as relative paths stay inside the same language folder. Paths to shared images need one more `../` in a language folder.

The language is used for the page's `<html lang>`, the on-screen text, the sidebar, and search.

## On-screen text

The theme has its built-in on-screen text in English only. For languages other than English, write the text for each language under `theme_options.strings`. Keys you do not write anywhere in `strings` appear in English.

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

The list of keys and the English text are under "On-screen text" in [theme_options](../reference/theme-options.md). For an example that writes all the text for `ja` and `ko`, see this documentation's [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml).

## Sidebar and search

The sidebar and search show only pages in the same language as the current page. You cannot search across languages.

In the automatic order, the group name is the first heading of the `index.md` in that folder inside the language folder. If there is none, it is the folder name.

To set the order with `nav.yml`, put a file such as `docs/_data/nav.ja.yml` for each language. If there is no file for the language, `nav.yml` is used. The items in `nav.yml` are not filtered by language; they appear as written. Write the URL of a translated page as `/ja/guide/config.html`.

## Switch languages

A page that has translations shows a language button in the header. Press it and choose a language from the list that opens. A page without a translation has no language button.

The language links are ordered with the site-wide language first, then the other languages by name.

The site name link in the header goes to the site root (the top page of the language in `lang`) from a page in any language.

## 404 page

The 404 page appears in the language of the site-wide `lang`.
