# 다국어

하나의 사이트에 여러 언어의 페이지를 둘 수 있습니다.

## 언어가 정해지는 방법

페이지의 언어는 파일 이름으로 정해집니다.

| 파일 이름 | 언어 |
| --- | --- |
| `config.md` | 사이트 전체의 언어(`lang`) |
| `config.ja.md` | `ja` |
| `config.zh-CN.md` | `zh-CN` |

- `.md` 바로 앞부분이 소문자 두 글자의 언어 코드(ISO 639-1)일 때 언어로 봅니다. `zh-CN`처럼 `-` 뒤에 지역을 붙일 수 있습니다.
- `node.js.md` 같은 이름은 언어로 보지 않습니다. `config.ts.md`처럼 끝부분이 우연히 언어 코드와 같은 이름은 그 언어가 됩니다.
- `lang`이 없으면 사이트 전체의 언어는 `en`입니다.

언어는 페이지의 `<html lang>`, 화면의 문구, 사이드바, 검색에 쓰입니다.

## 파일 배치

번역은 원래 페이지 옆에, 파일 이름에 언어를 더해 둡니다. 설정은 필요 없습니다.

```text
docs/
  index.md
  index.ko.md
  guide/
    config.md
    config.ja.md
    config.ko.md
```

- 페이지 사이의 링크는 같은 언어의 파일 이름으로 씁니다. 예를 들어 `config.ko.md`에서 첫 페이지로 가는 링크 대상은 `../index.ko.md`라고 씁니다. `index.md`로의 링크는 사이트 전체 언어의 페이지로 갑니다.
- 언어별 첫 페이지는 `index.<언어>.md`이고 URL은 `/index.<언어>.html`입니다.
- `README.<언어>.md`는 폴더의 첫 페이지가 되지 않습니다.

## 화면의 문구

테마가 가진 화면의 문구는 영어뿐입니다. 영어 이외의 언어에서는 `theme_options.strings`에 언어별로 문구를 씁니다. `strings` 어디에도 쓰지 않은 키는 영어로 나옵니다.

```yaml
theme_options:
  strings:
    ja:
      search_placeholder: ドキュメントを検索
      next: 次へ
```

키 목록과 영어 문구는 [theme_options](../reference/theme-options.ko.md)의 '화면의 문구'에 있습니다. `ja`와 `ko`의 문구를 모두 쓴 예는 이 문서의 [docs/_config.yml](https://github.com/akilasatolu/tiny-md2docs/blob/main/docs/_config.yml)입니다.

## 사이드바와 검색

사이드바와 검색에는 현재 페이지와 같은 언어의 페이지만 나옵니다. 언어를 넘나드는 검색은 할 수 없습니다.

자동 정렬에서 그룹 이름은 그 폴더의 `index.<언어>.md`(사이트 전체 언어는 `index.md`)의 첫 제목입니다. 없으면 폴더 이름입니다.

`nav.yml`로 정렬할 때는 언어별로 `docs/_data/nav.ja.yml` 같은 파일을 둡니다. 그 언어의 파일이 없으면 `nav.yml`을 씁니다. `nav.yml`의 항목은 언어로 걸러지지 않고 쓴 그대로 나옵니다. 번역한 페이지의 URL은 `/guide/config.ko.html`처럼 씁니다.

## 언어 전환

같은 폴더에서 언어를 뺀 이름이 같은 파일을 서로 번역으로 봅니다(`config.md`와 `config.ko.md`). 헤더에 언어 버튼이 나오고, 누르면 열리는 목록에서 언어를 전환할 수 있습니다. 번역이 없는 페이지에는 언어 버튼이 나오지 않습니다.

언어 링크는 사이트 전체의 언어가 맨 앞에, 나머지는 언어 이름 순으로 놓입니다.

헤더의 사이트 이름 링크는 어느 언어의 페이지에서든 사이트의 루트(`lang` 언어의 최상위 페이지)로 갑니다.

## 404 페이지

404 페이지는 사이트 전체 `lang`의 언어로 나옵니다.
