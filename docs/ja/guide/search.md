# 検索

ヘッダーの検索窓で、サイト内のページを検索できます。外部のサービスは使わず、ブラウザで検索します。検索窓に初めて入ったときに、ビルド時に作ったページの一覧を読み、今の言語の各ページを読み込んで本文を調べます。

## 使い方

- `/` キーで検索窓に移ります。
- 入力すると、タイトル、見出し、本文から一致するページが最大10件出ます。
- 結果が出ると、先頭のページが選ばれた状態(色付き)になります。↑↓ キーで選び直し、Enter で選んだページを開きます。Esc で結果を閉じます。
- Tab キーで、検索窓の右端の ×、結果の各ページの順に移れます。結果のページで Enter を押すと開き、Esc を押すと検索窓に戻ります。
- 入力中は、検索窓の右端の × で入力を消せます。

## 対応している言語

検索は、文字の種類によって照合の方法を変えます。

| 文字の種類 | 例 | 照合の方法 |
| --- | --- | --- |
| 漢字、ひらがな、カタカナ、ハングル | 日本語、中国語、韓国語 | 2文字ずつの組 |
| ラテン文字、キリル文字など、語を空白で区切って書く言語 | 英語、フランス語、ドイツ語、ベトナム語、ロシア語、アラビア語、ヘブライ語(母音記号を付けない書き方) | 単語 |

- 中国語の簡体字と繁体字は、別の文字として扱います。「設置」で「设置」は見つかりません。
- ロシア語の「й」と「и」、「ё」と「е」は、同じ文字として扱います。
- 語の間に空白を置かない言語(タイ語など)は、動作を保証しません。空白や記号の間がまるごと1語になるので、語の途中から検索しても見つかりません。
- 母音記号などの結合する記号を使う言語(タイ語、ヒンディー語、母音記号を付けたアラビア語やヘブライ語など)は、動作を保証しません。記号のところで語が切れるため、見つからないことや、関係のないページが混ざることがあります。
- 言語ごとの辞書は持ちません。語の区切りは、文字の種類だけで決めます。

## 日本語の検索

日本語は、2文字ずつずらした組(「設定変更」なら「設定」「定変」「変更」)で照合します。そのため、単語の区切りがなくても、文の途中の語が見つかります。

ただし、空白で区切らずに続けて入力した漢字・かな・ハングルは、タイトル、見出し、本文のどれかに**そのまま続いた形で**含まれるページだけが出ます。「東京都」で、「東京と京都」としか書いていないページは出ません。

検索の前に、次のように文字をそろえます。

- 全角の英数字と半角のカナは、ふつうの文字にそろえます。「ＡＢＣ」は「abc」で、「ｶﾞｲﾄﾞ」は「ガイド」で見つかります。
- カタカナとひらがなは区別しません。「がいど」でも「ガイド」が見つかります。
- 4文字以上のカタカナ語の末尾の長音「ー」は無視するので、「サーバー」と「サーバ」は同じになります。ひらがなで入力した4文字以上の語の末尾の「ー」も同じです。「コピー」「キー」のような短い語はそのままです。
- 英字の大文字と小文字、アクセント記号は区別しません。「café」は「cafe」で見つかります。
- 濁点と半濁点は区別します。「が」で「か」は見つかりません。

複数の語をスペースで区切ると、すべての語を含むページだけが出ます。

1件も見つからないときは、漢字、カタカナ、英数字に挟まれた助詞(の、を、に、は、が、で、と、へ、も、や、から、まで、より、など)を空白に置き換えて、もう一度探します。「設定の方法」で、「設定方法」と書いたページが見つかります。

## 検索の仕様

- 検索の対象: 今のページと同じ言語(`<html lang>`)のページだけです。言語を分ける方法は[多言語](i18n.md)を見てください。
- 語の分け方: 漢字、ひらがな、カタカナ、ハングルは、上の「日本語の検索」のとおり、2文字ずつの組にします。それ以外は、文字と数字の連なりを1語にします。`_`、`-`、`.` などの記号で区切るので、`optional_front_matter` は `optional`、`front`、`matter` の3語です。組は順位の点数に使います。一致するには、上の「日本語の検索」のとおり、続いた形で含まれる必要があります。
- 1文字の語: 組や単語として照合せず、その1文字がタイトル、見出し、本文のどこかに含まれるページを探します。
- 最後の語の前方一致: 単語で照合する言語では、入力の最後の語を前方一致で探します。「caf」で「café」が見つかります。
- 1文字違い: 単語で照合する言語で、4文字以上の語が一致しないときは、1文字違い(1文字の追加、削除、置き換え)の語も探します。「serch」で「search」が見つかります。文字の入れ替え(「seacrh」)は見つかりません。

## 順位

一致した場所ごとの点数を、入力した語ごとに足して、合計が大きい順に並べます。

| 場所 | 点数 |
| --- | --- |
| タイトル | 10 |
| 見出し | 4 |
| 本文 | 1(さらに、同じ語が出てくる1回ごとに 0.2。5回まで) |

- タイトルに、入力した語句の全体が含まれるときは、5 を足します。
- 1文字違いで一致した語は、点数が半分になります。
- 点数が同じときは、タイトルが短いページ、次に URL の順に並びます。

## 読み込む範囲

検索では、各ページの本文の全体を調べます。最初の検索では今の言語の全ページを読み込むので、ページが多いサイトや長いページがあるサイトほど時間がかかります。10 秒以内に読み込めないページは、タイトルでだけ見つかります。
