# 사이드바

사이드바에는 문서의 페이지가 나열됩니다. 순서는 두 가지 방법으로 정할 수 있습니다.

## nav.yml로 정렬하기

`docs/_data/nav.yml`을 두면 그 순서와 이름으로 나열됩니다.

```yaml
- title: 시작하기
  children:
    - title: 개요
      url: /
    - title: 설치
      url: /getting-started/install.html
- title: 자주 묻는 질문
  url: /faq.html
```

- `url`이 없는 항목은 그룹이 되어 `children`의 항목을 묶습니다.
- `children` 안에도 그룹을 만들 수 있습니다. `nav.yml`의 중첩은 48단계까지입니다(49단계 이상은 빌드가 실패합니다).
- `url`은 사이트 루트부터의 경로로 쓰고 끝은 `.html`로 합니다. 최상위 페이지는 `/`입니다.

## 폴더에서 자동으로 정렬하기

`nav.yml`이 없을 때는 `docs/` 안의 폴더 구성으로 사이드바를 자동으로 만듭니다.

예를 들어 다음과 같이 파일을 두었다고 합시다.

```text
docs/
  index.md              # 제목은 '개요'
  faq.md                # 제목은 '자주 묻는 질문'
  getting-started/
    index.md            # 제목은 '시작하기'
    install.md          # 제목은 '설치'
  guide/
    config.md           # 제목은 '설정'
    advanced/
      cache.md          # 제목은 '캐시'
```

사이드바는 다음과 같이 나열됩니다.

```text
개요
자주 묻는 질문
시작하기
  시작하기
  설치
guide
  설정
  advanced
    캐시
```

- 폴더의 단계는 `docs/`부터 셉니다. `docs/` 바로 아래의 페이지는 그룹에 넣지 않고 맨 앞에 놓습니다. 최상위 페이지(`index.md`)가 가장 먼저입니다.
- `docs/` 바로 아래의 폴더가 그룹, 그 안의 폴더가 하위 그룹이 됩니다. 그보다 깊은 폴더도 같은 방식으로 중첩되며 깊이에는 제한이 없습니다. 들여쓰기는 다섯 번째 단계부터 늘어나지 않습니다.
- 폴더의 `index.md`도 다른 페이지와 마찬가지로 항목이 됩니다. 첫 제목은 그룹 이름도 됩니다. `index.md`가 없으면 폴더 이름이 그룹 이름입니다(위 예의 `guide`와 `advanced`).
- 항목의 이름은 본문의 첫 제목입니다.
- 순서는 파일 경로 순입니다. 그룹 안에서는 페이지가 하위 그룹보다 먼저 놓입니다. 순서나 이름을 바꾸거나 페이지를 내지 않으려면 `nav.yml`을 씁니다.

언어별 정렬 방법은 [다국어](i18n.md)를 보세요.
